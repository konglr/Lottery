## 4. 直观解读

**问题**: 候选池只取 freq=0∪1 (≈ 67.5 个号码, 排除 freq=2∪3),  再去掉最冷 20 个 (按遗漏值), 命中率能不能提升?

**答案**:  
- 候选池 = 67.5 个 → 全选期望命中 = 67.5 × 20/80 = **16.875**  
- 去掉 20 冷号 → 池 ≈ 47.5 个 → 全选期望 = 47.5 × 20/80 = **11.875**  
  → 实际平均覆盖 = 11.875 / 11.875 ≈ **1.000 倍**, 与随机一致

**为什么会这样**:  
freq=2∪3 是 "高热度" 号码, freq=0 是 "遗漏深" 号码.  
- freq=2∪3 期望在 T 期出现 = 11.2+1.3 × 20/80 ≈ **3.125 个**  
- freq=0 期望在 T 期出现 = 33.7 × 20/80 ≈ **8.42 个**  
- freq=1 期望 = 33.8 × 20/80 ≈ **8.45 个**  
合计 = 20.0 (= T 期 20 红球), 这是数学恒等

你在 freq=0∪1 池里"自然就期望命中 16.875 / 20 = 84.4%" — 但这是因为你覆盖了 84.4% 的号码池, 不代表你有"预测能力".  
去掉 20 冷号后, 你覆盖变成 47.5/80 = 59.4%, 期望命中降到 11.875 / 20 = 59.4%.  
这是"成本-覆盖"的权衡 — 池子缩了, 自然命中数缩, 但每注投注的"集中度"提高了.

**所以**, 这个策略**没有"统计意义上的提升"** — 它只是把你的投注范围从 67 个缩到 47 个, 期望命中同步从 ~17 降到 ~12. 任何 Top N 选择在 freq=0∪1 池上, 倍率都贴 1.000.
