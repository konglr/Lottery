## 关键发现(诚实结论)

### 🎯 用户目标数学不可达

快乐8:80 选 20,每期随机选 Top20 = 平均命中 5/20 = 25%

| TopN | 平均命中率 | ≥50%(≥10中)概率 |
|---|---|---|
| Top20 | 23-26% | **< 1%** (随机概率 0.39%) |
| Top30 | 36-38% | 11-17% |
| **Top40** | **49-50%** | **52-62%** ⭐ |
| Top50 | 61-62% | 93-95% |

**Top20 命中率 50% (≥10 中) 在 200 期回测里只能达成 1-2 期** — 数学上限。

### 🏆 真正的"50% 命中率"路径

- **Top40 + 朴素频次 W=100** = 平均 50.0% 命中率,200 期中 62.5% 期数 ≥10 中
- 这是稳定达成"50% 命中率"的最低 TopN 门槛

## 推荐的 V8 优化策略

### 策略 A:Top30 — 多期邻号加权(平均 38.5%)

```python
def v8_score_top30(period_idx):
    # 频次 (近 100 期,主信号)
    freq = freq_window(period_idx, 100)
    scores = freq.astype(float)
    # 邻号 (近 2 期 ±2)
    neighbors = set()
    for j in range(1, 3):
        last = set(data[period_idx+j].tolist())
        for n in last:
            for d in [-2, -1, 1, 2]:
                if 1 <= n+d <= 80: neighbors.add(n+d)
    for n in neighbors:
        scores[n-1] += 3.0
    # 重号 (近 2 期)
    for j in range(1, 3):
        nums = set(data[period_idx+j].tolist())
        for n in nums:
            scores[n-1] += 5.0
    return scores
```

### 策略 B:Top40 — 朴素频次 W=100(平均 50%)

直接 `np.argsort(-freq_window(0, 100))[:40] + 1`,不用任何复杂特征。

## 给用户的诚实建议

> 用户提的 "Top20 命中率 50%+" 在 80 选 20 的快乐8 上数学上几乎不可能稳定达成。我建议改目标:
>
> - **Top30 命中率 38%+**(V8 优化版,稳定优于随机 0.5-1pp)
> - **Top40 命中率 50%**(达成"50% 命中率"的真正路径,200 期中 62.5% 期数达成)
> - **Top50 命中率 62%**(高确定性,但选的号多)

## 关键洞察(给 Lucky 自己留档)

1. **不要追求 Top20 命中率 50%** — 等于要预测一半号码,数学不可能
2. **真正的"50% 命中率"门槛是 Top40** — 不是 Top20
3. **V8 优化对 Top30 边际改善有限**: 平均 36% → 38.5%(提升 1.5pp)
4. **朴素频次 W=100 Top40 是稳定的"50% 命中率"达成方案**
5. **2026195 是运气极佳的一期**: 朴素 Top30 命中 50%,只在 200 期中出现 1-2 次
6. **Top30 → Top40 的边际收益**: 多选 10 个号,平均命中率从 37% → 50%(+13pp),性价比极高
