# FSW 方式 · Feature × Span Window × Weight(自适应版)

**记录时间**:2026-07-24 19:15 GMT+8  
**方法名**:FSW(Feature × Span Window × Weight) + **自适应参数优化**  
**核心思想**:用"多个 (F, S, W) 三元组"灵活组合评分,每期自动找最优参数

---

## 📌 FSW 三维度定义

| 字母 | 含义 | 取值 |
|---|---|---|
| **F**(Feature) | **特征** | span(跨期) / freq(频次) / miss(漏号) / repeat(重号) / neighbor(邻号) / anti_hot(反热号) / big_small(大小反转) |
| **S**(Span Window) | **往期覆盖量** | 1, 2, 3, 5, 7, 10, 30, 50, 100, 200 期 |
| **W**(Weight) | **该(F,S)组合的权重** | 0~1.5 的实数 |

### 关键特性:**(F, S, W) 三元组灵活组合**

```
FSW_得分(num) = Σ_i [F_i(num, S_i) × W_i]

示例配置(4 个三元组):
  1. (F=span,  S=2,   W=0.3)   ← 跨 2 期回溯
  2. (F=span,  S=10,  W=0.3)   ← 跨 10 期回溯
  3. (F=neighbor, S=1, W=0.3)  ← 上期邻号
  4. (F=span,  S=2,   W=0.5)   ← 跨 2 期回溯(加强)
```

## 🔄 自适应 FSW 系统设计

### 核心流程

```
1. 准备候选 (F, S, W) 三元组池(90 个)
2. 每期预测前,用过去 N 期(默认 30)数据评估每个候选
3. 贪心搜索:逐步添加最优三元组,直到无法提升
4. 用最优三元组给下期号码评分,选 Top 6/9/12
5. 重复 1-4,每期重新优化参数
```

### 关键参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| 回测窗口 N | 30 | 用过去 N 期数据评估参数 |
| 贪心上限 | 5 个三元组 | 最多选 5 个三元组组合 |
| 停止条件 | 增益 < 0.001 | 再加一个三元组提升 < 0.001 就停 |
| 评估指标 | Top 6 平均命中 | 6 红球单式平均命中数 |

### 自适应 vs 固定的取舍

| 维度 | 固定 FSW | 自适应 FSW |
|---|---|---|
| **优点** | 简单、可解释、参数稳定 | 能跟踪参数漂移、应对新模式 |
| **缺点** | 错过参数变化、对新模式不敏感 | 样本量小可能过拟合、计算慢 |
| **推荐场景** | 长期稳定市场 | 短期参数变化大 |

## 🔑 关键洞察

1. **S (Span Window) 选择对结果影响最大**
2. **双色球 span(2) 跨 2 期是最强单特征**(3.58/6,基线 1.09,3.3 倍)
3. **贪心 FSW 组合优于单特征**:3.58 → 3.84/6(+0.26)
4. **W 不必都大**:0.3 也能有贡献(0.5 反而稀释)
5. **自适应 FSW 跟踪参数变化**:但 30 期样本要谨慎

```python
import json
import pandas as pd

with open("data/backtest/adaptive_fsw_2026085.json") as f:
    record = json.load(f)

red_cols = [f"红球{i}" for i in range(1, 7)]
actual = sorted([int(df[df["issue"]==2026085].iloc[0][c]) for c in red_cols])
actual_set = set(actual)

print(f"2026085 实际:{actual}\n")

for n_pick in [6, 9, 12]:
    key = f"top{n_pick}"
    picks = record["next_period_2026085"][key]
    hits = sorted(actual_set & set(picks))
    print(f"自适应 FSW Top {n_pick}: 命中 {len(hits)}/{n_pick} = {hits}")
```
