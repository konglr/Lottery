## 📐 V4 评分公式 (V22 v2.1 + 方案 F)

### 完整公式

```python
score(num) = c5_score[num] + c10_score[num] + c30_score[num] + nbr_score[num]
           + c5_extra[num]            # 方案 F
           + c2_score[num]             # 方案 F
           + c3_score[num]             # 方案 F
```

### 各项定义

#### 1. c5_score (V22 v2.1 主评分)
```python
c5_score[c5 == 0] = +0.3   # 5 期未出 (冷号, 略加分)
c5_score[c5 == 1] = +0.3   # 5 期出 1 次
c5_score[c5 == 2] = +0.3   # 5 期出 2 次
c5_score[c5 == 3] = -0.8   # 5 期出 3 次 (偏热, 减分)
c5_score[c5 == 4] = -0.8   # 5 期出 4 次 (热)
c5_score[c5 == 5] = -0.8   # 5 期出 5 次 (热)
c5_score[c5 >= 6] = -1.5   # 5 期出 6+ 次 (过热)
```

#### 2. c10_score (V22 v2.1 中期频次)
```python
c10_score[c10 == 0] = +0.2
c10_score[c10 == 1] = +0.4
c10_score[c10 ∈ [2,4]] = +1.0  # 最佳区间
c10_score[c10 ∈ [5,6]] = -0.3
c10_score[c10 >= 7] = -0.8
```

#### 3. c30_score (V22 v2.1 长期频次)
```python
c30_score[c30 <= 2] = -0.2
c30_score[c30 ∈ [3,4]] = +0.2
c30_score[c30 ∈ [5,10]] = +0.5  # 最佳区间
c30_score[c30 >= 13] = -0.7
```

#### 4. nbr_score (邻号加权, V22 v2.1)
```python
for num in data[last_i]:  # 上期开奖
    for d in [-2, -1, 1, 2]:
        if 1 <= num+d <= 80:
            nbr_score[num+d-1] += 0.3
nbr_score /= 20  # 归一化
```

#### 5. **c5_extra** (方案 F 增强: c5 减分)
```python
c5_extra[c5 == 3] = -c5_w_penalty * 0.5
c5_extra[c5 == 4] = -c5_w_penalty * 0.8
c5_extra[c5 >= 5] = -c5_w_penalty * 1.5

# 最优配置: c5_w_penalty = 0.0 (实证该权重影响小)
```

#### 6. **c2_score** (方案 F 核心: c2=1 加分)
```python
c2_score[c2 == 0] = 0.0   # c2=0 不加权 (实证: 命中率 0%, 绝对冷号)
c2_score[c2 == 1] = +0.6  # c2=1 加分 ⭐⭐⭐ KEY
c2_score[c2 >= 2] = 0.0   # c2=2 (前 2 期都出) 不加权

# 最优配置: c2_w_hot = 0.6
```

#### 7. **c3_score** (方案 F 核心: c3=1 加分)
```python
c3_score[c3 == 0] = 0.0   # c3=0 不加权
c3_score[c3 == 1] = +0.4  # c3=1 加分 ⭐⭐
c3_score[c3 >= 2] = 0.0   # c3=2 不加权

# 最优配置: c3_w_hot = 0.4
```

## 📊 选号规则 (V5 放宽)

### V4 → V5 变更

V4 用户反馈 (2026-08-01 17:08): "20 胆 4 区位 5/5/5/5 太严格需要放松一点"

**V5 设计**: 20 胆 **4 区位放宽到每区 3-8 个**:
```python
# 第一轮: 每区最少 lo=3 个 (保证每区都有)
for z in [0, 1, 2, 3]:
    for idx in np.argsort(scores)[::-1]:
        if zone_count[z] >= lo: break
        num = idx + 1
        if zone_of(num) == z:
            select(num)

# 第二轮: 按全局分数填到 20, 每区最多 hi=8 个
for idx in np.argsort(scores)[::-1]:
    if len(selected) >= 20: break
    num = idx + 1
    if zone_count[zone_of(num)] >= hi: continue
    select(num)
```

### 实证基础 (200 期实际开奖 4 区位分布)
| 指标 | 区 1 | 区 2 | 区 3 | 区 4 |
|---|---|---|---|---|
| 平均 | 4.92 | 5.11 | 5.04 | 4.93 |
| **P5** | **3** | **3** | **2** | **2** |
| P50 | 5 | 5 | 5 | 5 |
| P95 | 7 | 8 | 8 | 7 |
| 最大 | 9 | 10 | 10 | 10 |

**结论**: 5/5/5/5 太严格, 应该放宽到 [2-8] 之间。**V5 采用 lo=3, hi=8** 是最安全的。

### N 胆选号 (4/6/10) - 从 20 胆中取前 N 高分
```python
sorted_20 = sorted(twenty_picks, key=lambda n: scores[n-1], reverse=True)
N_dan = sorted_20[:N]  # 纯评分驱动, 不限区位/跨度/连号
```

**V5 关键**: 
- 20 胆 4 区位放宽 [3-8] (中间范围)
- N 胆 = 20 胆中评分前 N 个, **无 4 区位配额/跨度/连号约束**

## 🎓 方案 F 核心哲学

### 实证关键发现 (200 期回测)

| 特征 | 命中率 | 选号逻辑 |
|---|---|---|
| c2=0 (前 2 期未出) | **0.00%** | 绝对冷号, **绝对不选** |
| c2=1 (前 2 期出 1 次) | 50.00% | **中度热号, 加分** ⭐ |
| c3=0 (前 3 期未出) | 0.00% | 绝对冷号 |
| c3=1 (前 3 期出 1 次) | 33.54% | 中短期热号, 加分 |
| c5=0 (前 5 期未出) | 0.00% | 绝对冷号 |
| c5=2 (前 5 期出 2 次) | 40.37% | 温号 |

### 为什么 c2=0 / c3=0 命中率 0%?

**数学必然性**: 80 选 20 时, 2 期 40 个号 + 本期 20 个号 = 60 个不同号, 占 80 个的 75%。
**剩下 20 个号"前 2 期都未出", 但实际开奖 20 个号必然至少 1 个与前 2 期重叠**。
**因此 c2=0 的号在 80 选 20 的游戏中下期"必不出现"**。

(注: 这是 200 期回测的统计结论, 实际有极少例外)

### 方案 F 的选择

- **c2=1 加分 (0.6)**: 强制选"前 2 期出 1 次"的号 (= 实际开奖最可能出现的号)
- **c3=1 加分 (0.4)**: 强化中短期热号信号
- **c2=0 不加权**: 绝对冷号不进 4 胆
- **c5=3-5 减分**: 避免 c5 过热号

## 📋 关键规则总结

### 必选规则 (V6):
1. **20 胆 4 区位 每区 3-8** (V5 放宽: 每区最少 3, 最多 8) ⭐
2. **N 胆 = 20 胆中评分前 N** (无 4 区位/跨度/连号约束)
3. **c2=1 和 c3=1 加分** (短期热号加权)
4. **c5=3-5 减分** (避免过多重号, 可选参数 c5_w_penalty=0.0)
5. **单期重号约束** (V6 新增: L1≤11, L2≤11, L3≤7) ⭐

### 不该做的:
1. ❌ c2=0 加分 (实证 0% 命中率)
2. ❌ c3=0 加分 (实证 0% 命中率)
3. ❌ 4 胆满足 4 区位 1/1/1/1 (V5 评分优先于 4 区位均衡)
4. ❌ 20 胆 4 区位 5/5/5/5 严格 (V4 太严格, V5 放宽到 3-8)
5. ❌ 在 20 胆中限制跨度/连号 (V4 评分已经自然处理)
6. ❌ 20 胆与上期重号 > 11 (V6 约束, P75 阈值)

### 调优参数 (200 期回测最优):
- `c5_w_penalty = 0.0` (实证 0.3 和 0.5 影响小)
- `c2_w_hot = 0.6` ⭐ (关键参数)
- `c3_w_hot = 0.4` ⭐ (关键参数)
- `20_dan_min_per_zone = 3` ⭐ (放宽)
- `20_dan_max_per_zone = 8` ⭐ (放宽)
- `max_l1 = 11` ⭐ (V6 约束)
- `max_l2 = 11` ⭐ (V6 约束)
- `max_l3 = 7` ⭐ (V6 约束, 偏 L3 因为 c3 加分)
