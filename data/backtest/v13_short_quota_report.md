## 🏆 V13 v4 最终方案

**核心思路**: **用学到的相关系数作为权重,而不是直接用短期格子出号数**

```python
def v13_v4_select(i, S=5, top_n=20, w_corr=5.0):
    cls = F_CLASS[i]
    s = score_v10(i).copy()  # V10 反向分数
    
    if i + S < n_periods:
        # 计算短期 S 期格子分布
        grid_count = np.zeros((4, 4))
        for j in range(1, S+1):
            nums = data[i+j]
            for n in nums:
                grid_count[cls[n-1]-1, ZONE[n-1]-1] += 1
        
        # 仅对 |corr| > 0.1 的格子加权
        for c in [1, 2, 3, 4]:
            for z in [1, 2, 3, 4]:
                mask = (cls == c) & (ZONE == z)
                if abs(corrs[c-1, z-1]) > 0.1:
                    avg_grid = S * 20 / 16
                    delta = (grid_count[c-1, z-1] - avg_grid) / avg_grid
                    s[mask] += w_corr * corrs[c-1, z-1] * delta
    
    return np.argsort(-s)[:top_n]
```

## 🎓 关键洞察 (Lucky 留档)

1. **短期 S=5 期确实有信号** — 不是噪声, 13/16 格子有显著相关性
2. **V13 v4 = V10 + 学到的相关系数加权** 是有效方案
3. **为什么"简单用短期格子分布做配额"会失败**: 直接替换选号顺序会破坏 V10 的核心信号
4. **正确做法是 "加权微调"**: V10 分数 + (corr × 短期格子出号偏离),而不是替换
5. **V13 v4 vs V12 是不同方向的优化**:
   - V12 优化"高命中"概率 (≥10中 3.5%)
   - V13 v4 优化"平均命中率" (27.5%)

### 推荐组合策略

- 如果追求 **平均命中率** → 用 **V13 v4**
- 如果追求 **≥10中 高命中概率** → 用 **V12**
- 如果想要 **平衡** → 同时跑 V13 v4 和 V12,综合两者共识号
