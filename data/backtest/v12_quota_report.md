## 🎯 任务

> V11 调整为在 4 个热号区,和 Z1-Z4 区,分别选择一定数量的号码。同时考虑其他特征的优化,回测一下这个方案能否更好

## 📐 方案设计

**16 格子框架** = 4 频次类 (高频/中高/中低/低频) × 4 区位 (Z1=1-20, Z2=21-40, Z3=41-60, Z4=61-80)

策略:
1. **基础**: V10 反向特征评分 (4 类已经隐式包含)
2. **配额约束**: 
   - `min_quota`: 某些格子强制选 X 个 (最小配额)
   - `max_quota`: 某些格子最多选 X 个 (上限)
3. **剩余 TopN 填充**: 按 V10 分数排序,补充剩余名额

## 🎯 V12 选号代码

```python
def v12_select(i, top_n=20, min_q=None, max_q=None):
    """V12: V10 + 4类×4区 配额约束"""
    from collections import Counter
    
    freq = feat_freq(i, 100)
    cls = classify_freq(freq, [0.25]*4)
    ZONE = np.array([((n-1)//20) + 1 for n in range(1, 81)], dtype=int)
    s = score_v10(i)  # V10 反向评分
    
    sorted_idx = np.argsort(-s)
    selected = []
    cell_count = Counter()
    
    # 1. 满足最小配额
    if min_q:
        for (c, z), q in min_q.items():
            mask = (cls == c) & (ZONE == z)
            indices_in_group = np.where(mask)[0]
            if len(indices_in_group) == 0: continue
            group_scores = s[indices_in_group]
            order = np.argsort(group_scores)
            for p in indices_in_group[order[:q]]:
                if p not in selected:
                    selected.append(p)
                    cell_count[(c, z)] += 1
    
    # 2. 按 TopN 补充
    for idx in sorted_idx:
        if len(selected) >= top_n: break
        c, z = cls[idx], ZONE[idx]
        if max_q and (c, z) in max_q and cell_count[(c, z)] >= max_q[(c, z)]:
            continue
        if idx in selected: continue
        selected.append(idx)
        cell_count[(c, z)] += 1
    
    return np.array(selected)

# 推荐配置
min_q_v12 = {(1, 1): 2, (2, 1): 2}   # Z1 高频+中高 各 ≥2
max_q_v12 = {(4, 4): 3}                # 类4 Z4 ≤ 3

# 使用
selected = v12_select(target_idx, top_n=20, min_q=min_q_v12, max_q=max_q_v12)
nums = sorted((selected + 1).tolist())
```

## 🎓 关键洞察

1. **V12 是 V10 的"修正版"**,不是替代。两者共识度 80%。
2. **配额约束的真正价值**:
   - **min Z1 类1+类2 各 2** = 修复 V10 在 Z1 区选少的问题 (-112 + -63)
   - **max 类4 Z4 ≤ 3** = 修复 V10 在 类4 Z4 选多的问题 (+143)
3. **平均命中率略降** (5.425 → 5.345),但**"高命中"概率大幅提升** (1% → 3.5%)
4. **16 格子诊断是关键**: 通过对比 V10 vs 实际开奖,精确找到优化空间
5. **V12 选号和 V10 共识 80%**,验证了 V12 是 V10 的"温和修正"
